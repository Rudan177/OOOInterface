# OOOInterface 使用教程

## OOOInterface 通用词汇

- 主页面：OOOInterface 主页面，包括搜索框、搜索引擎切换按钮、搜索历史框、底部铭牌。
- 搜索框：屏幕中央处长条栏目，支持文本键入。
- 搜索引擎切换按钮：搜索框下方按钮。
- 搜索历史框：记录搜索历史，仅在有搜索记录时展开。
- 快速访问链接：添加至主页面的网页链接快捷按钮。
- 底部铭牌：屏幕底部铭牌，标有"OOOInterface"。
- 壁纸模式：仅保留搜索框、搜索引擎切换按钮，并显示壁纸的页面。
- 右键菜单：随动快捷栏。
- 设置页面：OOOInterface 设置页面，包括多项内容设定。
- 必应（Bing）每日壁纸：通过云端拉取 Microsoft Bing 提供的壁纸为 OOOInterface 带来多样化的壁纸体验。
- 高级视觉效果：为用户提供毛玻璃等更加精美的视觉体验（可能会增加性能消耗）。
- 壁纸常显示：在主页面仍然显示壁纸（推荐同时打开「壁纸缩放」）。
- 快速访问侧边栏：为快速访问链接提供全新侧面板样式。
- 开发者模式：为用户提供更多设置项（测试），可能不稳定。
- 关于页面：展示当前版本核心信息和历史版本信息。
- 反馈页面：OOOInterface 收集用户反馈的页面。

## 安装 OOOInterface

1. Chrome浏览器，进入chrome://extensions/。
2. 开启右上角的"开发者模式"。
3. 点击"加载已解压的扩展程序"。
4. 选择本项目所在文件夹。
5. 新建浏览器标签页。
6. 进入欢迎页面。
7. 点按空格进行下一步。
8. 进入主页面。

## 主页面使用

### 搜索与导航

#### 搜索框操作

- 默认情况下，打开页面后搜索框将自动获得焦点，用户可直接键入内容。
- 按 Enter 键执行搜索，搜索结果将跳转至当前搜索引擎的结果页面。
- 搜索框内有内容时，右侧将出现清除按钮，点击即可一键清空搜索内容。
- 在搜索框内右键可快速粘贴剪贴板内容。

#### 搜索引擎切换

搜索框下方提供 Google 与 Bing 两个搜索引擎切换按钮，点击即可切换当前使用的搜索引擎。在设置页面开启「引擎锁定」后，搜索引擎将被固定，切换按钮不可点击。

#### 搜索历史

在搜索框内输入内容时，下方会自动弹出匹配的历史记录列表供快速选取；也可通过快捷键 Ctrl+H 手动展开或收起。右键菜单中的「搜索历史」选项可切换该功能的开与关。历史记录仅保存在本地，随时可在设置中关闭此功能。

#### 状态栏

屏幕顶部显示当前日期与时间，双击状态栏本身可快速切换秒钟的显隐。需先在设置中启用。

#### 壁纸模式

在主页面状态下，向下滚动鼠标滚轮即可进入壁纸模式——此时页面将仅保留搜索框、搜索引擎切换按钮及完整的壁纸背景，为用户提供沉浸式的搜索体验。向上滚动即可返回主页面。

> 注：若已在设置中开启「壁纸常显示」，壁纸将常驻于主页面，向下滚动仍可同时触发壁纸模式的沉浸式效果。

### 右键菜单

在页面任意空白处右键单击即可唤出随动快捷栏（右键菜单）。菜单分为固定选项与勾选切换项两类：

- 固定选项（始终显示）：复制、粘贴、设置、刷新、关于、反馈。
- 勾选切换项：右键菜单中的功能切换项（如搜索历史、壁纸常显示等），默认显示部分项目，可在设置页面自定义最多三项的显示内容。

可在设置页面中进一步自定义菜单的显示样式与包含的项目。

### 快速访问链接

快速访问链接是主页面上的一排快捷按钮，可快速跳转至常用网站。

- 管理链接：在设置页面选择「管理链接」，即可对快速访问链接进行增删改查操作。
- 导入与导出：支持将快速访问链接导出为 JSON 文件备份，或导入外部 JSON 文件快速恢复链接列表（同名同址重复项将自动跳过）。

## 设置

### 基础操作

#### 设置页面

设置页面是个性化您的 OOOInterface 的重要窗口。在这里您可以自由定制您的 OOOInterface。

- 打开设置页面：您可以通过双击或右键单击底部铭牌，或在右键菜单中点击「设置」来打开。
- 完成和保存设置：完成设置后，点击「完成」保存更改。按下「ESC」或点击右上角关闭按钮可关闭设置页面。
- 返回上一个设置项：部分设置项会在右侧面板中展开，完成后可点击右上角返回按钮或按下「ESC」返回。
- 重置：单击重置按钮将清空所有设置项，请谨慎操作。

### 外观设置

#### 主题设置

OOOInterface 为用户提供了多样化的主题，并提供了上传主题的入口和官方主题商店。

若您需要上传自己的主题，点击「+」按钮，找到主题目录，选中主题文件，点击确认（不同操作系统使用体验可能略有不同）即可。您也可以通过拖拽将主题文件拖入。

#### 字体设置

OOOInterface 为用户提供了丰富的免费字体，并提供了上传字体的入口。

若您需要上传自己的字体，点击「+」按钮，找到字体目录，选中字体，点击确认（不同操作系统使用体验可能略有不同）即可。您也可以通过拖拽将字体文件拖入。

#### Logo 设置

OOOInterface 为用户提供了多样化的 Logo，并提供了自定义文字 Logo 和上传 Logo 的入口。

若您需要上传自己的 Logo，点击「+」按钮，找到字体目录，选中图片文件，点击确认（不同操作系统使用体验可能略有不同）即可。您也可以通过拖拽将图片文件拖入。

#### 自定义文字 Logo

在 Logo 设置下拉菜单中选择「自定义文字Logo」，即可展开文字输入框。在输入框中输入您想展示的文字后，点击右侧确定按钮即可完成设置。

#### 配色方案

OOOInterface 为用户提供多种预设配色方案，涵盖经典与新兴风格：
- 林绿色、经典蓝、黑白色：经典三色系，适配不同使用场景。
- 天依蓝、活力红、典藏金、隔离色：新增风格系，提供更为丰富的视觉选择。

用户可在「选择配色」下拉菜单中直接选取，配色更改将即时生效。

#### 壁纸设置

- 壁纸来源：用户可根据需求选择壁纸来源，包括默认壁纸、必应每日壁纸（通过云端拉取 Microsoft Bing 提供的壁纸并保持每日更新）、URL链接（填入图片网络链接）以及本地图片（点击「+」按钮选择或直接拖拽）。在设置页面点击「必应每日壁纸」旁的信息图标可了解详细说明。
- 壁纸常显示：开启后，壁纸将在主页面常驻显示，不再需要滚动即可看到完整背景。建议同时开启「壁纸缩放」以获得更佳的视觉比例。
- 壁纸缩放：开启后，壁纸将按照屏幕比例进行缩放填充，避免出现黑边或裁切过多内容。此选项仅在「壁纸常显示」开启时可见。

### 功能设置

#### 状态栏

- 打开方式：在设置页面勾选「状态栏」开关即可启用。
- 显示秒钟：开启状态栏后，可进一步勾选「显示秒钟」以在状态栏中显示精确到秒的时间。

#### 高级视觉效果与增强显示

- 高级视觉效果：开启后将启用毛玻璃等动态模糊效果，为界面增添层次感，但可能会增加部分性能消耗。
- 增强显示：开启后将展示全新的光照效果，进一步提升界面的视觉质感。该选项仅在「高级视觉效果」开启时可见。

> 注：「高级视觉效果」和「增强显示」均为独立功能，用户可根据自身设备性能灵活组合使用。

#### 搜索历史

搜索历史功能会自动记录用户的搜索关键词，并保存在本地。

- 开启后，当用户在搜索框内输入内容时，下方将自动弹出匹配的历史记录列表。
- 用户可直接点击历史记录条目以快速执行搜索。
- 在设置页面可随时关闭此功能。

#### 右键菜单设置

右键菜单提供三种样式，可在设置页面「右键菜单样式」中切换：

| 样式 | 说明 |
|------|------|
| 默认 | 完整网格布局，显示全部图标与文字 |
| 紧凑 | 图标与文字并列，布局更节省空间 |
| 极简 | 仅显示图标，不显示文字，同时禁用自定义菜单项功能 |

勾选切换项的显示数量最多三项，可在设置页面「右键菜单样式」右侧面板中点击右上角的设置图标（自定义菜单项）进行增减。可选项目包括：搜索历史、壁纸常显示、高级视觉效果、引擎锁定、隐藏弹窗、禁止提示。

#### 快速访问链接设置

- 侧边栏样式：开启「快速访问侧边栏」后，快速访问链接将以侧面板形式展示于页面右侧，需从左侧边缘呼出。
- 显示图标：开启后，侧边栏中的链接按钮会显示网站图标（若获取失败则显示名称首字母作为占位）。

#### 隐藏弹窗与禁止提示

- 隐藏弹窗：开启后，版本更新等通知弹窗将不再自动弹出，适合已熟悉更新内容的用户。
- 禁止提示：开启后，首次进入页面时关于新功能的提示弹窗将不再显示。

### 快捷键

在设置页面开启「快捷键」后，可使用以下快捷键操作：

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 快速聚焦到搜索框 |
| `Ctrl + ,` | 打开设置页面 |
| `Ctrl + H` | 展开 / 收起搜索历史框 |
| `Ctrl + S`（设置页面内） | 应用当前设置 |

### 手柄控制器

OOOInterface 支持游戏手柄操作，方便用户在连接手柄后进行浏览操作。

- 在设置页面勾选「手柄控制器」开关即可启用，连接手柄后屏幕中央会出现跟随光标。
- 启用后可配置左摇杆按下和右摇杆按下时的对应操作（如打开设置、刷新页面、切换搜索历史、切换壁纸常显示等）。
- 部分手柄还可在设置中调整光标速度及反转 A/B 键的映射关系。

##### 环形快捷菜单

按住 LB 键或单击 X 键可呼出环形快捷菜单（Radial Menu），松开右摇杆或方向键确认所选操作，按 B 键或 ESC 键退出。菜单包含以下八项操作：清空搜索框、粘贴剪贴板内容、打开设置、打开关于页面、切换搜索引擎、切换壁纸模式、刷新页面、复制搜索框内容。

| 按键 | 功能 |
|------|------|
| 左摇杆 | 控制光标移动 |
| 右摇杆 / 方向键 | 导航跳转，聚焦下一可交互元素 |
| LT（左扳机） | 清空搜索框内容；在搜索历史条目上聚焦时删除该条目 |
| RT（右扳机） | 将剪贴板内容粘贴至搜索框 |
| A | 确认 / 点击当前光标所指向的元素；长按底部铭牌可打开设置页面 |
| B | 返回 / 取消（关闭弹窗、收起侧边栏、退出快捷菜单等） |
| X | 呼出环形快捷菜单，松手确认选择；菜单包含：清空、粘贴、设置、关于、搜索切换、壁纸模式、刷新、复制 |
| Y | 执行确认（等同 Enter）；在搜索框时触发搜索，在设置页时执行应用操作 |
| LB | 在滑块调节界面时减少数值；长按呼出环形快捷菜单 |
| RB | 在滑块调节界面时增加数值 |
| 左摇杆按下 | 可自定义操作（打开设置 / 刷新页面 / 切换搜索历史 / 切换壁纸常显示） |
| 右摇杆按下 | 可自定义操作（同上） |

### 开发者模式

开发者模式暴露了更多调试与高级设置项，供进阶用户使用。

可用功能包括：
- 字体大小调节：通过滑块或数值输入框调整全局字体缩放比例（0.5x ~ 2.0x）。
- 字体粗细调节：调整文字字重（100 ~ 900），自动四舍五入至 100 的整数倍。
- 搜索框厚度调节：调整搜索框的高度（0 ~ 600px）。
- 代理端口配置：选择或自定义本地代理端口，支持 8899（本地转发）、7890（Clash 默认）、8080 及 10809（V2Ray）等常用端口，也支持手动输入其他端口号。
- 修改完成后，点击「应用」保存更改，或点击「重置开发者模式」恢复出厂值。

## 辅助页面

### 关于页面

关于页面展示了当前版本的核心信息、版本号及历史版本记录。

- 打开方式：在设置页面点击右上角的「关于」按钮，或在主页面右键菜单中点击「关于」。
- 更新日志：在设置页面右上角的「关于」按钮上右键单击，可打开更新日志页面，查看详细的版本变更内容。

### 反馈页面

反馈页面为用户提供了向开发者提交意见与建议的渠道。

- 打开方式：在设置页面点击右上角的「反馈」按钮，或在主页面右键菜单中点击「反馈」。
- 开发者模式下反馈按钮始终可见；非开发者模式下反馈按钮默认隐藏。
