# OOOInterface 轻松升级指南

> 本指南介绍两种升级 OOOInterface 的方式：**官网下载解压** 和 **OOOInterface 易升（OUA）**。推荐优先使用 OUA，体验更省心。

---

## 方式一：从官网下载解压

适合希望手动控制、或网络环境受限无法使用 OUA 的用户。

### 步骤

1. 打开 [OOOInterface 官网](https://rudan177.github.io/OOOInterface/index.html)，选择版本卡片进入下载页面。
2. 下载对应操作系统的最新压缩包（`.zip`）。
3. 关闭 OOOInterface 所有标签页（否则文件可能正在被占用）。
4. 将下载的压缩包**解压覆盖**至 OOOInterface 安装目录（保留原有配置文件，主要覆盖 `index.html`、`css/`、`js/` 等核心文件即可）。
5. 回到 `chrome://extensions/` 页面，点击 OOOInterface 卡片上的 **刷新** 按钮。
6. 新建一个标签页，确认版本已更新。

> **提示**：若不想覆盖全部文件，也可以直接下载完整的 ZIP，将整个解压后的文件夹重命名后替换原来的扩展目录。

## 方式二：使用 OOOInterface 易升（OUA）

> **OOOInterface Update Assistant**（简称 OUA）是配套 OOOInterface 的桌面工具，可自动检测新版本、一键更新、管理安装目录，并支持开机自启、最小化到托盘等习惯设置。

### 获取 OOOInterface 易升

> 从 [OOOInterface 易升下载站](https://rudan177.github.io/OOOInterface/OUA/PB) 下载 OOOInterface 易升。

---

### 界面概览

OUA 启动后呈现三栏式布局，分为**左 - 中-右**三个区域：

| 区域 | 名称 | 说明 |
|------|------|------|
| 左侧大卡片 | **更新面板** | 显示安装目录、当前版本、远程版本、更新通道，并提供检查与更新操作 |
| 右上卡片 | **通知面板** | 展示官方推送的重要通知（如重大版本更新、维护公告等） |
| 右下卡片 | **关于本软件** | 显示 OUA 自身版本号、操作系统类型，并提供检查更新的入口 |

---

### 首次安装（零配置启动）

OUA 首次运行时，若未检测到有效安装目录，会引导你完成初始化：

1. 启动 OUA，界面中央显示「未设置」的安装目录。
2. 点击 **「更换」** 按钮，弹出系统文件夹选择对话框，选择 OOOInterface 的安装目录（即 `chrome://extensions/` 中 OOOInterface 的路径）。
3. OUA 会自动检测目录状态，并给出对应引导：

   - **空目录** → 弹出三选项对话框：
     - **从远程拉取**：默认使用 LTS 通道，自动从 GitHub 克隆最新代码到目标目录。
     - **从本地导入**：弹出文件选择框，让你导入已有的 ZIP 压缩包。
     - **取消**：退出流程。
   - **完整目录** → 直接进入正常更新检测流程。

---

### 日常更新

目录设置完成后，日常使用只需两步：

1. **检查更新**：点击主按钮「检查更新」，OUA 会自动读取本地版本并与 GitHub 远程分支比对。
2. **执行更新**：若发现新版本，按钮变为「立即更新」，点击后 OUA 会在后台静默下载并覆盖文件，完成后自动刷新界面。

> 若本地版本高于远程正式版，OUA 会提示「当前版本高于正式版，是否加入尝鲜版？」，用户可选择切换到尝鲜版通道。

---

### 更新通道（分支管理）

更新面板中的「更新通道」支持两种顶层模式，各有三个子选项：

#### 远程模式

自动从 GitHub 获取更新，适用于网络通畅的环境。

| 子分支 | 说明 |
|--------|------|
| **长期支持版（LTS）** | 稳定优先，适合日常使用，更新频率较低 |
| **正式版（main）** | 跟随主干开发，功能较新，稳定性与 LTS 相当 |
| **尝鲜版（test）** | 包含最新实验性功能，更新最频繁，可能存在不稳定因素 |

切换分支时，OUA 会智能比对当前版本与各分支的远程版本，自动推荐最合适的目标分支；若智能判断失败，也会弹出三按钮手动选择。

#### 本地模式

跳过网络检测，直接通过 ZIP 压缩包导入更新。适合：
- 断网或网络受限环境
- 测试人员分发自定义版本
- 内网部署场景

切换到本地模式后，主按钮变为「导入」，点击后弹出文件选择框；也可以直接将 ZIP 文件**拖拽到 OUA 窗口**，松开后自动完成导入解压。

### 设置面板

点击更新面板中的 **齿轮图标**，可展开顶部开关区；齿轮图标右侧还有一个**独立的完整设置弹窗**，包含以下三类设置：

#### 1. 启动与托盘

| 开关 | 功能 |
|------|------|
| **开机启动** | 系统启动时自动运行 OUA，无需手动打开 |
| **最小化到托盘** | 关闭窗口时隐藏至系统托盘（任务栏旁小图标），不退出程序，双击托盘图标或热键可重新唤出窗口 |

> 开启「最小化到托盘」是**热键功能的前置条件**，未开启时 ESC 快捷键不生效。

#### 2. 自动更新

| 开关 | 功能 |
|------|------|
| **自动更新** | 检测到新版本时自动下载，完成后等待用户手动确认安装 |

#### 3. 热键（需在「最小化到托盘」开启时显示）

| 项目 | 说明 |
|------|------|
| **热键开关** | 启用全局快捷键 |
| **打开窗口** | 默认 `Ctrl+Shift+O`，可点击「改」自定义——点击后键盘区域闪烁，此时按下任意组合键即设定为新热键；点击「↺」可重置为默认值 |
| **ESC 关闭** | 开启最小化到托盘后，按 `ESC` 可快速隐藏 OUA 窗口（仅当对话框/设置弹窗未打开时生效） |

#### 4. 网络代理设置

解决 GitHub 访问受限问题（常见于国内网络环境）。

- **自动配置代理**：OUA 自动读取系统代理设置，适合大多数使用 Clash / V2Ray 等代理工具的用户。
- **手动配置代理**：勾选「启用代理」后展开 IP 和端口输入框，填入代理服务器地址（如 `127.0.0.1`）和端口号（如 `7890`、`10809`）。

代理修改后点击「应用」立即生效，无需重启。

#### 5. 可访问性（供高级用户）

- **可访问开关**：启用后可访问性 API，允许外部程序通过 HTTP 接口操控 OUA。
- **端口**：可访问服务监听的端口，默认 `8964`。
- **OOOInterface 访问**：允许 OOOInterface 通过本地接口与 OUA 通信（通常保持开启）。
- **外部访问开关**：允许局域网内其他设备通过令牌访问 OUA 服务。
- **访问令牌**：用于身份验证的 Token，可点击「编辑」按钮修改、点击「复制」按钮复制、点击「重新生成」按钮更换。
- **状态指示条**：实时显示服务器运行状态（绿色圆点 = 运行中，灰色 = 未运行）。

#### 6. 系统操作

| 按钮 | 功能 |
|------|------|
| **关闭并重启** | 保存当前设置并重启 OUA，使设置立即生效 |
| **恢复出厂设置** | 清除所有用户配置（代理、热键、启动项等），操作不可撤销，需二次确认 |

### 通知与关于面板

#### 通知面板

- 自动从云端拉取官方通知，展示重要公告（如重大版本变更、维护提醒）。
- 每次打开 OUA 时自动刷新，无需手动操作。
- 通知内容点击可跳转至对应详情页面。

#### 关于本软件面板

- 显示 OUA 的短版本号（如 `0.9.3`）和完整版本号（如 `0.9.3-BS112`）。
- **单击版本号**可展开详细信息，包括完整版本、操作系统、当前更新状态。
- 版本号旁的**圆点**表示有可用更新，点击「检查更新」按钮可触发 OUA 自身的更新流程（下载新版本安装包，点击「更新」后打开安装包完成覆盖安装）。
- 底部显示联系方式 `wyjcrtu@proton.me` 和版权声明。

### 拖放导入（本地模式特有）

在本地模式下，OUA 支持**拖放文件**功能：

1. 将更新通道切换至「本地」。
2. 用鼠标将 `.zip` 压缩包拖入 OUA 窗口。
3. 窗口会出现半透明遮罩提示「释放 ZIP 文件以导入」。
4. 松开鼠标，OUA 自动完成解压覆盖，无需额外点击。

> 此功能同样支持在远程模式下拖放，拖放后会自动切换到本地模式再导入。

---

### 卸载

OUA 提供内置卸载功能：

1. 点击更新面板底部的**垃圾桶图标**（一键卸载）。
2. 按卸载向导提示操作，将清理 OUA 自身文件及注册表项。
3. 卸载完成后 OOA 自动退出。

> 卸载 OUA **不会影响**已安装的 OOOInterface 扩展本身，如需同时移除扩展，请自行在 `chrome://extensions/` 中操作。

## 两种方式对比

| 特性 | 官网下载解压 | OUA 易升 |
|------|-------------|---------|
| 操作难度 | 中等，需手动找目录 | 低，图形化引导全程 |
| 自动化程度 | 无，全手动 | 自动检测 → 自动下载 → 自动覆盖 |
| 网络要求 | 需手动下载压缩包 | 远程模式需联网，支持代理配置 |
| 分支管理 | 需手动选择下载对应版本 | 一键切换 LTS / main / test |
| 拖放导入 | 不支持 | 支持本地 ZIP 拖放 |
| 热键唤起 | 不支持 | 支持自定义热键（默认 Ctrl+Shift+O） |
| 开机自启 | 不支持 | 支持 |
| 托盘后台运行 | 不支持 | 支持 |
| 自动更新 | 不支持 | 支持 |
| 代理配置 | 需手动设置系统代理 | OUA 内置代理设置，即时生效 |
| 通知推送 | 无 | 自动拉取官方通知 |

## 常见问题

**Q：OUA 提示"无法获取远程版本，请检查网络"？**
A：可能是网络环境问题。可在 OUA 设置 → 网络代理设置中开启代理，或使用自动配置模式；也可临时切换到本地模式导入 ZIP 压缩包。

**Q：更新后 OOOInterface 没有生效？**
A：请回到 `chrome://extensions/` 页面点击 OOOInterface 的「刷新」按钮，然后新建标签页确认版本已更新。若仍未生效，可尝试禁用再重新启用该扩展。

**Q：OUA 窗口关掉了怎么重新打开？**
A：
- 若开启了「最小化到托盘」，双击托盘图标或按默认热键 `Ctrl+Shift+O` 唤出。
- 若未开启托盘，可在开始菜单搜索 "OOOInterface Update Assistant" 或 "易升" 启动。

**Q：OUA 会自动更新 OOOInterface 吗？**
A：在「自动更新」开关开启且处于远程模式时，OUA 检测到新版本会自动下载，但不会自动安装，仍需点击「立即更新」确认。

**Q：OUA 和 OOOInterface 是什么关系？**
A：OUA 是 OOOInterface 的配套桌面工具，负责更新管理，本身不是浏览器扩展。两者由同一团队开发，配合使用体验最佳。

**Q：可以同时使用两种方式吗？**
A：可以。两种方式互不影响，选择最适合你当前场景的方式即可。

**Q：OUA 会收集我的数据吗？**
A：OUA 仅在更新检测时访问 GitHub API，所有操作均在本地完成，不上传任何个人信息或扩展数据。
